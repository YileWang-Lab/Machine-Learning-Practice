## 怎么做作业

**一、在你自己的账号下建仓库**

1. 打开本仓库页面，点击右上角的 **Use this template** → **Create a new repository**
2. 在弹出的页面中，在**你自己的账号**下创建一个**同名仓库**（建议可见性选 **Private**）

**二、clone 到本地做作业**

3. 把你**自己账号下**的这个仓库 clone 到本地：

   ```bash
   git clone https://github.com/<你的用户名>/机器学习练习.git
   cd 机器学习练习
   ```

4. 进入对应题目目录（例如 `题目一/`），按该目录下 README 的要求完成作业

**三、push 回去**

5. 把成果提交并推送回你自己账号下的仓库：

   ```bash
   git add .
   git commit -m "完成题目一"
   git push
   ```

6. 把仓库 URL 交给老师；如需老师直接查看，在仓库 **Settings → Collaborators** 中把老师加为协作者

---

## 注意

- **请勿直接向本仓库 push 代码。** 本仓库只作为任务书与数据源，是所有同学的公共模板。
- 作业请全部提交在**你自己账号下的副本仓库**中，不要在本仓库开分支或提 Pull Request。
- 每个题目独立评分，请在各题目自己的目录下组织代码与图片。
